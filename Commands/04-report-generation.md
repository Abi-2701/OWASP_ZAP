# ZAP Report Generation

### 1. Open the Reports Menu
In OWASP ZAP, open the **Report** menu.

### 2. Generate the HTML Report
1. Select the report-generation option.
2. Choose the HTML report format.
3. Select the alerts and details to include, as required.
4. Choose the output location and filename.
5. Generate the report.

### 3. Verify the Report File
Confirm that the generated HTML report exists and opens correctly in a browser.

### 4. Review Risk Summary
Check the report for:
- Alert names
- Risk and confidence levels
- Affected URLs
- Evidence and descriptions
- Recommended solutions

### 5. Preserve Assessment Evidence
Keep the generated HTML report and relevant ZAP screenshots in the project repository.

### 6. Document Limitations
Record that automated scan results require manual validation before classifying an alert as a confirmed vulnerability.
